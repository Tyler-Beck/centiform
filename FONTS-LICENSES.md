# Font licenses

Every font in Centiform is an open-licensed Google Fonts family, downloaded from Fontsource
(https://fontsource.org) at authoring time and committed as woff2 files inside the one design
folder that uses it. No family is used by more than one design. `tools/fonts.mjs` appends a row
here when it vendors a new family. Design 095 uses the browser default serif and ships no font.
